# Skill taxonomy

The tag vocabulary offered across Projet — judging, project claims,
and search. Distinct from `skills.md`, which ranks a shortlist per
role for the ninety-second picker; every name here is reachable by
typing, and a name already ranked in `skills.md` is written exactly
as it appears there so the seed treats them as one skill.

Type is `hard` unless the section heading is marked `(soft)`.
Capabilities listed on the section heading are the rollup for names
that are not already mapped in `capabilities.md`.

A skill named `Communication` is omitted: that word is already a
capability, and a profile showing both under the same label reads as
a bug. Use the more specific communication tags instead.
